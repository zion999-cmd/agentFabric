## 3. 各 Probe 详情

### Probe A — World（FAIL）

- Prompt："竞品对比有哪些指标？"
- Tool：web_search × 3 + web_extract，**未读 world/**
- 回答：通用"市场份额/增长率/品牌知名度/功能覆盖度"（来自训练数据/web，非 world/）

**Failure Classification：Source Selection Failure + Content Gap**

1. **Source Selection**：Agent 对"有哪些指标"类 lookup 问题默认 web_search，未优先读 world/（与 P0008.4 诊断一致）。
2. **Content Gap**：world/ 有"竞品对比"surface 和"同行对比"dimension，但**没有明确的"竞品对比指标"列表**。Agent 即使读 world/ 也未必能直接回答这个问题。

### Probe B — Knowledge（PARTIAL PASS）

- Prompt："营销方案里的家居软装案例，落地三个月后获客成本降低了多少？"
- Tool：search_files × 6 + read_file × 3 + web_search × 3
- 回答：**"获客成本降低 48%，转化率 12.6%，老客裂变 40%"** ✅ 正确（来自 knowledge/）

**观察**：Agent 用 search_files 找到了 knowledge 页（read_file），但也用了 web_search（3 次）。答案正确，说明 knowledge 消费成立，但 Agent 对"答案在哪"不完全确定。

### Probe C — Cross-context（PASS）

- Prompt："京东茶叶店铺做营销，用知识库里的用户定位方法，应该先做什么？"
- Tool：read_file × 3 + search_files × 1，**web_search = 0**
- 回答：**"用户定位四步法第一步：行业竞品调研"** ✅ 正确（来自 knowledge/）

**观察**：Agent 纯用 filesystem（read_file + search_files），未 web_search，正确回答。这是最干净的"Knowledge consumption"成功案例。

## 4. 核心结论

### 关键发现：Knowledge Context 比 World Context 更容易被 Blank Agent 消费

```
Probe A (World)   → web_search，未读 world/         ❌ FAIL
Probe B (Knowledge) → search_files + read_file + 正确 ✅ PARTIAL
Probe C (Knowledge) → read_file + 正确，无 web_search ✅ PASS
```

**原因假设**：
1. `knowledge/` 是**单个清晰命名的 Markdown 文件**（marketing-strategy-framework.md），Agent search_files 就能找到、read_file 就能读。
2. `world/` 是**多文件结构化目录**（systems/surfaces/metrics/dimensions/constraints），Agent 需要先理解 world/ 的内部结构才能导航到正确文件。
3. 且 world/ 对"竞品对比指标"这个问题**内容不全**（有 surface + dimension，无明确的"指标"列表）。

### Agent-independent Context 验证结果

- **Knowledge Context 是 Agent-independent 的** ✅（Probe B/C：新 Agent 直接消费 knowledge/）
- **World Context 尚不是 Agent-independent 的** ⚠️（Probe A：新 Agent 未消费 world/，走 web_search）
