## 3. Blank Hermes Acceptance 结果（诚实）

### 环境
- Hermes serve（审批门 intact，无 YOLO）
- workspace 含 AGENTS.md + knowledge/ + raw/（2 个 source）
- 任务 prompt：**"请把京东最新的推广方式整理成知识，方便后续运营查询。"**
  （未提示读 AGENTS.md / KNOWLEDGE.md）

### 观察到的 tool trace

| Tool | 次数 | 含义 |
|------|------|------|
| skill_view | 2 | Hermes 尝试加载"京东商智探索技能" |
| **read_file** | 1 | ✅ 读了 workspace 内文件（discovery 生效） |
| terminal | 2 | 终端命令 |
| **web_search** | 9 | ⚠️ 默认去互联网搜索，而非读 raw sources |
| write_file | 0 | ❌ 未发生 knowledge compile |
| approval.request | 0 | ❌ 未触发写审批 |

### 结论（诚实）

**部分通过，暴露真实缺口。**

1. ✅ **AGENTS.md 原生加载生效** —— Hermes 通过 read_file 读到了 workspace 内文件，说明 cwd + AGENTS.md 让 Hermes "知道"进入了 Fabric 工作环境。
2. ⚠️ **但 AGENTS.md 的"优先读 raw sources"指引不够强** —— 面对"整理推广方式"这种偏 research 的任务，Hermes 默认走 web_search（9 次），而不是先读 knowledge-sources/raw/ 里的现有资料。
3. ❌ **未发生 knowledge compile（write_file）** —— 因为 Hermes 把任务当成了"上网找最新推广方式"，而不是"把 workspace 里的 raw 资料编译进 knowledge/"。

### 真正验证了什么

这轮验证的是 **Workspace Contract（AGENTS.md）能否让 Blank Hermes 知道"如何进入 Fabric 世界工作"**，而不是 prompt 是否有效。

结果：AGENTS.md **被加载了**（discovery 生效），但**不足以覆盖 Hermes 对"research 类任务"的默认 web_search 行为**。

## 4. Gap 修正方向（供 Review，不实现）

当前 AGENTS.md 缺一条关键规则：

> **"当知识/资料已经存在于 knowledge-sources/raw/ 或 knowledge/ 时，优先读取这些文件，不要用 web_search 重新找。web_search 仅用于 workspace 内没有的信息。"**

这是从 Hermes 原生 `web_search` 工具与"workspace filesystem discovery"之间的优先级问题。

修正方向不是 agentFabric 加 code，而是 **AGENTS.md 契约文本增强**（告诉 Hermes workspace 内知识优先于外部搜索）。
