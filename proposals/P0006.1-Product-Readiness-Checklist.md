P0006.1 Product Readiness Checklist
目标

验证当前 Workspace、HermesAgent、Runtime 是否已经达到真实可使用状态。

不是测试代码。

不是测试单元测试。

而是验证：

一个人今天能不能坐下来真正使用 agentFabric。

1. Workspace Navigation

检查：

所有 Sidebar 是否可以点击
每个 View 是否能够正常切换
不允许出现 Placeholder
不允许出现 Empty View
不允许 Console Error

输出：

PASS / FAIL

View:
Runtime
Chat
...
2. Runtime View

检查：

Execution History

是否正常加载

Execution Detail

是否正常展开

Signal

是否显示

Evidence

是否显示

Collect Button

是否真正触发 Runtime

Mock

是否完成一次 Collect

Execution 是否刷新

3. Chat

检查：

输入一句：

帮我分析今天的数据

验证：

Hermes 是否收到

Intent 是否识别

Skill 是否选择

Kernel 是否调用

Response 是否返回

Workspace 是否显示

整个 Agent Loop 是否完成

4. Runtime API

验证：

GET /api/runtime/status

GET /api/runtime/executions

GET /api/runtime/executions/:date

POST /api/runtime/collect

全部返回正常。

错误输入：

必须返回合理错误。

5. Chat API

验证：

POST /api/chat

测试：

Collect

Ranking

Signals

Evidence

General Question

全部能够正常响应。

6. Skill Registry

验证：

GET /api/chat/skills

检查：

全部 Skill 可见。

handler 存在。

不存在 Dead Skill。

不存在 Duplicate。

7. Runtime Data Flow

执行：

Collect

验证：

Collect

↓

Kernel

↓

Binding

↓

Connector

↓

Signal

↓

Evidence

↓

Execution

↓

Workspace

每一步都有真实数据。

8. Workspace Refresh

连续执行：

Collect

Collect

Collect

验证：

Execution History

自动刷新。

Detail

同步刷新。

不存在缓存问题。

9. Error Handling

人为制造：

不存在日期

错误参数

未知 Skill

未知 API

Workspace

不能崩。

必须给出错误提示。

Workspace 是否达到：

✓ 可以每天使用

还是

✗ 仍属于开发 Demo

必须说明原因。
