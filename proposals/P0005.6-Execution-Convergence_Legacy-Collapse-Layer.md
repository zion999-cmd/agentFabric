P0005.6 — Execution Convergence & Legacy Collapse Layer
🎯 一、目标（非常明确）
👉 只有 1 个目标：

让系统只有一条真实执行路径：Runtime Kernel

🧱 二、核心原则（必须写进 ADR）
Principle 1: Kernel is the ONLY runtime entry point
Principle 2: CLI / CDP / Legacy Connector cannot execute directly
Principle 3: All execution must pass through Blueprint → Kernel → Executor
Principle 4: Generated artifacts are runtime dependencies, not static files

✅ After（P0005.6）
CLI
  ↓
Runtime Kernel
  ↓
Execution Pipeline
  ↓
Binding Layer
  ↓
Connector (JD only implementation)

👉 只剩一条路径
