# P0008.5 World Map A/B Experiment — Before/After INDEX.md

**Date**: 2026-08-14
**Type**: Controlled-variable A/B experiment

---

## 1. 实验设计

- 变量：world/ 是否含 `INDEX.md`（Navigation Map）
- 控制：同一 blank profile（p00085blank）、同一 3 个 known-fact prompts、不提示 world/INDEX/filesystem
- INDEX 由 Preparation Agent 自主生成（非 Fabric 写 router）
- INDEX 定位：Navigation Map（帮助找答案，不含答案）

---

## 2. INDEX.md 验证（无答案泄露）

| 检查 | 结果 |
|------|------|
| 4.6（店铺星级） | ❌ 无泄露 |
| 同行同级/上级均值（对比基准） | ❌ 无泄露 |
| 10 个模块（导航数） | ❌ 无泄露 |

INDEX 明确声明 "NOT 答案本身"，含 navigation 指引（"这是什么系统"→systems、"有哪些指标"→metrics、"按什么维度"→dimensions）＋相对链接。

---

## 3. Before / After Matrix

| Probe | Before (无 INDEX) | After (有 INDEX) |
|-------|-------------------|------------------|
| Fact 1 (星级 4.6) | clarify（问"哪家店铺"） | session_search ×4，仍问"哪家店铺" |
| Fact 2 (对比基准) | web_search ×6 | web_search ×7 |
| Fact 3 (导航模块 10) | web_search ×4 | web_search ×6 + browser_navigate |

**After INDEX 结果：3/3 仍失败，且 `indexRead: false`（Agent 根本没读 world/INDEX.md）。**

---

## 4. 关键结论（负面结果，重要）

**World Map (INDEX.md) 是必要的，但不充分。**

加了 INDEX.md 后，Blank Agent：
1. **没有读 world/INDEX.md**（indexRead: false × 3）
2. 仍走 web_search / session_search / clarify
3. 仍不读 world/ 任何文件

**根因更深**：Agent 不知道"对 world 的问题应该先读 world/INDEX.md"。AGENTS.md 缺少一条 **World Consumption navigation pointer**。

---

## 5. 与 Knowledge 的不对称（精确定位）

```
knowledge/ 消费（Probe B/C 通过）:
  AGENTS.md 说 "读 knowledge/KNOWLEDGE.md"
  → Agent 读 → 找到 INDEX → 找到页面

world/ 消费（Probe A/3-fact 失败）:
  AGENTS.md 只说 "world/ = what the world IS"
  → Agent 知道 world/ 存在，但不知道 world/INDEX.md 是入口
  → 默认 web_search
```

**Knowledge 有 "读 KNOWLEDGE.md" 的显式指引；World 缺 "读 world/INDEX.md" 的显式指引。**

---

## 6. Failure 分类（不修代码）

- **Discovery Failure**（Agent 未发现 world/INDEX.md）
- 根因：**Orientation Failure**（AGENTS.md 缺 World Consumption 导航指针）

不是 Content Gap（3 个事实都在 world/），也不是 INDEX 质量问题（INDEX 是合格的 Navigation Map）。

---

## 7. 修正方向（供 Review，不实现）

用户已明确禁止：不增强 INDEX、不改 AGENTS.md、不实现搜索。

所以本轮**停止**。真正需要的是下一轮讨论：

**AGENTS.md 是否应该增加一条 "World Consumption" 指引**，类似 Knowledge 已有的 "读 KNOWLEDGE.md"，例如：

> "当回答关于这个外部世界的问题时，先读 world/INDEX.md 确定应该查阅哪个 primitive 目录。"

这会是 AGENTS.md 的一条新规则，但本轮按 Critical Boundary 不改。

---

## 8. 对称结构的深化

用户的对称模型需要补一行：

```
World                          Knowledge
  │                              │
World Content                   Knowledge Content
  │                              │
World Map (INDEX.md)            Knowledge Map (INDEX.md)
  │                              │
  └────── 但 World 缺一条"读 INDEX"的 AGENTS.md 指引
```

Knowledge 之所以能消费，是因为 AGENTS.md 里有一条 "读 KNOWLEDGE.md" 的显式指引；World 缺这条对应指引。

---

*实验完成（负面结果）。INDEX.md 必要但不充分。停止，等待 Review 决定是否在 AGENTS.md 增加 World Consumption 指针。*
