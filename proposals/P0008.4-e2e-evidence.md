## 4. 关键边界（诚实说明）

### 已证明
- ✅ 目录结构 + governance + fixtures + projection
- ✅ raw source immutable（fixture + 测试）
- ✅ 编译页带 provenance（sources frontmatter）
- ✅ knowledge/ 在 Fabric Workspace 中，Blank Hermes session cwd 可指向并发现

### 未在本轮 E2E 中执行的（需 Hermes 文件写权限）

- **Agent Compilation（raw → 新 knowledge 页）**：这是 Hermes 的 write_file tool 能力，受审批门保护。本轮 E2E 验证了"读取/发现"闭环，未验证"写入/编译"（避免绕过 Hermes 安全审批门）。
- **one-source-multi-page update**：作为 GOVERNANCE RULE 已在 KNOWLEDGE.md 中指定并测试（"One source may update multiple pages"），但真实执行需 Hermes 写权限。
- **conflicting-source preservation**：作为 GOVERNANCE RULE 已指定并测试（"PRESERVE / Never silently overwrite"），真实执行需 Hermes 写权限。

这三个是"Agent Compilation"行为（Runtime 按 KNOWLEDGE.md 治理执行），不是 agentFabric 代码。agentFabric 提供结构 + 治理，Hermes 执行编译。编译的写路径受 Hermes 审批门保护——这正是架构上正确的边界（agentFabric 不绕过 Hermes 安全）。
