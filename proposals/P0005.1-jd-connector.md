# P0005.1: JD Business Data Connector (京东商智)

Status: Proposed
Date: 2026-06-30
Depends on: P0005 (Business Data Foundation), P0004 (Runtime Control Plane)

---

## Objective

实现京东商智（sz.jd.com）数据获取能力，验证 P0005 Business Data Pipeline 的完整链路：

```
Acquisition → Raw Evidence Store → Parsers → Normalization → Business Context → Evidence Chain
```

这不是 JD API，不是 JD SDK。这是**京东商智数据获取能力**——从登录、采集、存证、解析、标准化到业务上下文的完整生命周期。

## Data Flow

### 1. Login (一次性 / 按需)

用户通过 Chrome 登录京东商智（sz.jd.com），浏览器保存 session。

```
Chrome (port 9222 debug mode)
  └── sz.jd.com (已登录)
        └── Cookies: __jda, __jdb, sdtoken, JSESSIONID, shop_monkey, _t ...
```

### 2. Acquisition (采集)

```
Option A: CDP Connect (Live)
  playwright-core chromium.connectOverCDP('http://localhost:9222')
    └── page.route('**/szgateway.jd.com/**')
          └── 拦截 SPA 自身的 API 调用
                └── 修改 POST body 中的日期参数
                      └── 捕获 response body (raw JSON)

Option B: Mock (Dev/Test)
  从 agentCMS data/daily_records.json 导入的历史样本数据
```

### 3. Parse (解析)

```
Raw JD API JSON
  │
  ├── summary.ajax response:
  │     jdr_sch_trade_deal_ord_ord_amt_sz_trade_deal_snapshot → gmv
  │     jdr_sch_trade_deal_ord_ord_qtty_sz_trade_deal_snapshot → orders
  │     jdr_sch_traffic_brow_sku__page_cnt_traffic_plat_item_di_sz_bsg → visitors
  │     jdr_sch_user_deal_ord_user_cnt_sz_user_deal_snapshot → customers
  │     fo_jdr_sch_industry_deal_rate → conversion_rate
  │
  ├── trend.ajax response:
  │     24h 数组 → hourly_sales[] / hourly_traffic[]
  │
  └── productTop.ajax response:
        SKU 排名列表 → top_products[]
```

### 4. Evidence Store (存证)

```
data/evidence/jd/
  2026/
    06/
      30_summary.json      ← raw API response
      30_trend.json
      30_productTop.json
      30_metadata.json     ← EvidenceMetadata (source, hash, time, method)
      30_screenshot.png    ← page screenshot (CDP mode)
```

### 5. Normalize (标准化)

```
ParsedJdData
  └── normalizeJdMetrics() [已有]
        └── EnterpriseSignalPayload {gmv, orders, uv, cvr, roi, ...}
              └── normalizeSignal() [已有]
                    └── EnterpriseSignal → SQLite signals 表
```

### 6. Business Context (业务上下文)

```
EnterpriseSignals
  └── BusinessContext:
        Store: 店铺名称、行业、星级
        Products: 商品列表 (SKU + SPU)
        Traffic: 流量来源 TOP5
        Advertising: 广告投放 ROI
        Inventory: 库存健康度
        Competitors: 行业排名

每个 Business Context 字段引用:
  → Evidence ID
    → Raw JSON
      → Screenshot
        → DOM
```

## Mock Mode vs Live Mode

| | Mock Mode | Live Mode (CDP) |
|---|---|---|
| **数据来源** | agentCMS daily_records.json | szgateway.jd.com API |
| **依赖** | 无 | Chrome debug mode (port 9222) |
| **认证** | 无需 | 用户手动登录京东商智 |
| **用途** | 开发、测试、CI | 生产采集 |
| **CLI** | `cli collect jd jd_shop_001 --mock true` | `cli collect jd jd_shop_001 --mock false` |
| **默认** | ✅ 默认 | 需显式指定 |
