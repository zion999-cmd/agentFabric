## 3. 真实 Hermes E2E 证据

### 环境

- Hermes v0.20.0，`hermes serve --skip-build --port 9119`
- `HERMES_DASHBOARD_SESSION_TOKEN` 用于 WS 认证（`?token=`）
- profile: `default`（含 AGNES_API_KEY，模型 agnes-2.5-flash）

### 结果

```
[1] Projected 9 files, hash 781848e37aea   ← 确定性投影
[2] Connected to Hermes serve /api/ws       ← WebSocket JSON-RPC
[3] session.create → session_id = e0c51840  ← cwd = FabricWorkspace
[4] response: "OK"                          ← prompt.submit → 完整回复
✅ E2E PASS
```

### 复杂 prompt（验证 filesystem-native discovery）

```
prompt: "读取 workspace 里的世界知识文件，然后告诉我京东商智有哪些核心指标？"
→ 触发 2 次 tool.start（模型自主读取 workspace 文件）
→ 32 chars 文本累积
→ 180s timeout（agnes-2.5-flash 多文件推理慢，非代码问题）
```

**关键结论**：模型**自主触发了 filesystem 读取**（2 次 tool call），证明 Hermes 能通过 cwd 找到并读取 Fabric Workspace 的世界知识。慢是模型速度问题，不是架构问题。

## 4. 关键协议发现（修正）

Hermes `/api/ws` 事件流（源码确认）：

| 原假设 | 实际 |
|--------|------|
| 文本在 `event.text` | 文本在 `event.payload.text` |
| 完成信号 `turn.end` | 完成信号 `message.complete`（`payload.text` = 完整文本） |
| 无 auth（loopback） | 需 `?token=<HERMES_DASHBOARD_SESSION_TOKEN>` |

这些已修正到 HermesSessionClient 和 Bridge 的 `collectTurn`。
